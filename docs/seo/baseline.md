## Architecture

- Next.js 14 App Router, React 18, TypeScript, Tailwind.
- Static and dynamic pages live under `app/`.
- Legacy location content is driven by `lib/locations.ts`.
- New authoritative territory data is isolated in `lib/serviceTerritories.ts`; it is not a router guard and does not hide or delete legacy URLs.
- Route metadata is defined per page plus `app/layout.tsx`.
- Sitemap and robots are generated by `app/sitemap.ts` and `app/robots.ts`.
- Structured data is generated by `lib/structuredData.ts` and additional inline JSON-LD on state pages.

## Sitemap, robots, canonical, and metadata baseline

- Sitemap base host: `https://srenergy.us`.
- `metadataBase`, most location/product canonicals, structured data, and robots sitemap host: `https://srenergy.com`.
- Both hosts are therefore present in canonical signals.
- Sitemap-only URLs without matching app pages: `/products/texas-vpp`, `/calculator`, `/faq`, `/privacy`.
- App pages omitted from the sitemap include `/privacy-policy` and `/terms-of-service`.
- `/contact` and `/contact/` both appear in the static sitemap list.
- Existing copy repeatedly states 30 or 30+ states although the authoritative scope is 19 states plus DC.

## Forms, APIs, and analytics baseline

- `app/components/ContactForm.tsx` submits name, phone, email, state, bill, product interests, and message to `/api/contact`.
- The state selector offers all 50 states plus DC, not the authoritative service list.
- Browser-required consent is not included in the JSON payload and is not validated or stored server-side.
- `/api/contact` sends email through Resend and writes a Notion lead; inputs are interpolated into HTML without an observed escaping layer.
- `/api/enrich-lead` is marked shelved but remains routable and can create a Notion lead before invoking the shelved pipeline.
- `/api/metrics` reads Airtable metrics.
- No Google Analytics, GTM, Meta Pixel, PostHog, Segment, Plausible, or Clarity integration was found in reviewed app source.

## Verification posture

The Phase 1 additions are data/design/test artifacts only. They do not alter production routing, page copy, canonical output, sitemap output, forms, APIs, or automation. Known baseline discrepancies remain explicit HOLD items instead of being silently changed.

A production build with non-secret placeholder values for the import-time `NOTION_API_KEY` and `FIRECRAWL_API_KEY` checks completed successfully and generated 738 static pages. A local production server check confirmed:

- `/robots.txt` and `/sitemap.xml` return 200.
- The sitemap contains 185 URLs.
- The four sitemap-only URLs return 404.
- Texas VPP and a non-Texas catch-all VPP URL both return 200.
- Canonical samples are split between `.com` and `.us`, matching the source audit.
